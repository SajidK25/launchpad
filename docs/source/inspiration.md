# Product and Design References

## Product feature inspiration

Reference: https://www.producthunt.com/

Use this site to understand familiar launch-platform patterns, such as:
- daily product listings and ranking presentation
- voting and comment interactions
- maker/founder profiles
- topic browsing and discovery
- launch-day engagement patterns

Do not copy Product Hunt branding, content, UI, or proprietary behavior.
The Launchpad client brief and REQ documents remain the source of truth.

## Visual design inspiration

Reference: https://nicklaunches.com/

Use this site for design direction only:
- clean launch-focused layout
- typography, spacing, visual hierarchy, cards, and responsive behavior
- modern but restrained product presentation

Do not reproduce its exact layout, branding, assets, or copy.
Create an original Launchpad visual system.

## Image generation and visual assets

Reference MCP: https://higgsfield.ai/mcp

When approved visual assets are needed, use the configured Higgsfield MCP.
Generated images must be original, relevant to the feature, and suitable for commercial use.
Do not generate images for precise diagrams, data charts, or text-heavy UI elements.
